## Onboarding video guides

The Help page uses fresh Polling Pops screen recordings of isolated, synthetic demo
workspaces. The older OpenRound files remain at their original URLs for compatibility,
but are no longer the videos shown in Help. English captions and transcripts match the
spoken narration; no customer content, email inboxes, or production credentials are recorded.

Re-record with `pnpm guides:capture`, using the isolated in-memory Playwright fixture,
then render with `EDGE_TTS=/path/to/edge-tts pnpm guides:render`. The renderer requires
FFmpeg, FFprobe, Python 3, and Edge TTS. It checks streams and fully decodes both outputs
before publishing. Review UI, narration, feature availability, and provider distribution
terms again before a public release. Do not record against production or real users.
