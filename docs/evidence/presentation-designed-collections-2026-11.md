# Presentation designed collections

Public design research and original implementation brief, November 13, 2026.

## Inspection scope

Nine individual templates were opened from the current public
[Canva presentation catalog](https://www.canva.com/presentations/templates/). Each full-size cover
and the specified full-size interior were inspected through the public detail-page slideshow.
Slide counts were verified against its page controls. Other interior arrangements mentioned below
were visible in the thumbnail strip; the remaining slides were not individually inspected.
The catalog establishes availability, not popularity, usage, customer demand or editor behavior.
Customer jobs below are interpretations of the template framing and visible structure.

The actionable pattern is a coordinated composition grammar. Typography, density, framing,
motifs and hierarchy recur across different page arrangements. A palette change alone does not
produce this distinction. A strong set also includes useful interiors rather than concentrating
its identity only in the cover.

## Original Polling Pops families

These are the planned directions for the eight existing family IDs. They are original briefs,
not reproductions of the referenced templates. Each family contains the same eight functional
layouts: `cover`, `section`, `body`, `split`, `image_left`, `image_right`, `data` and `closing`.
The target is 64 editable native layouts with family-specific proportions and hierarchy.

| Family ID                 | Direction and composition grammar                                                                                                                                                                                                                                                                                                                              |
| ------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `studio` — Studio         | **Cobalt modern business.** Broad sans headlines, decisive cobalt fields, pale accent geometry and open margins. Cover balances a large title against a substantial geometric area. Section/closing pages shift the balance; body/split pages use clear rails; image layouts give media a deliberate share; data uses oversized values and compact labels.     |
| `editorial` — Editorial   | **Sand serif brand proposal.** Large serif statements, small sans labels, fine rules and offset columns. Cover reads as a considered editorial spread. Section/body/closing pages use uneven margins and generous pauses; split/image pages pair a narrow narrative with a wider feature; data is restrained and ruled.                                        |
| `midnight` — Midnight     | **Ink and neon startup.** Dark ink fields, bright accent markers and strong sans hierarchy. Cover uses a short large statement and a directional geometric counterweight. Section/closing pages are emphatic; body/split pages alternate compact evidence and open space; images are prominent; data leads with a large metric.                                |
| `blueprint` — Blueprint   | **Corporate cobalt project.** Structured sans headings, compact technical labels, alignment rails and numbered geometry. Cover resembles a project brief with a clear identifier. Section/body/split layouts preserve an orderly grid; image layouts have explicit captions; data prioritizes readable rows and comparisons; closing isolates the next action. |
| `terracotta` — Terracotta | **Clay organic wellness.** Warm clay fields, serif statements and oversized soft geometric forms. Cover pairs a quiet title with an offset rounded composition. Section/closing pages leave breathing room; body/split pages use relaxed asymmetric columns; images have generous frames; data remains simple and calm.                                        |
| `signal` — Signal         | **Coral creative brief.** Bold coral field, compact heavy sans headings, large numbers and assertive angular marks. Cover prioritizes a brief statement. Section/closing pages use strong changes of scale; body/split layouts separate the key claim from support; image pages use contrasting proportions; data gives one result visual priority.            |
| `monograph` — Monograph   | **Black and white portfolio.** Monochrome contrast, large sans titles, small index labels and strong rectangular framing. Cover uses typography and negative space. Section/body/closing pages behave like an indexed publication; split/image layouts favor a large work area with a narrow caption rail; data uses clean rules and restrained emphasis.      |
| `canvas` — Canvas         | **Rose pastel workshop.** Soft rose field, friendly sans hierarchy, rounded panels and offset tabs. Cover invites participation with a large prompt. Section/closing pages keep a generous central statement; body/split layouts provide clear activity areas; image layouts read as examples; data uses legible grouped results and labels.                   |

Across all eight roles, the family controls title size, weight, alignment, text width, shape
placement and the relationship between primary content and supporting material. Image slots are
editable placeholders. Shared localized demonstration copy and explicitly illustrative data let
authors compare designs without confusing visual style with subject-specific content templates.

The implementation uses original native text, shapes, rules and bounded styling. It does not
copy or redistribute Canva artwork, photographs, wording, fonts, screenshots, layouts or other
expressive assets. Public references inform abstract product decisions. No competitor asset is
added to the repository; original code and demonstration content follow
[the clean-room contribution rules](../../CONTRIBUTING.md) and the repository's Apache-2.0 license.

## Foundation and verification boundary

The foundation for this increment is optional bounded named palettes, per-node typography and
shape appearance in scene schema **9** / document schema **18**. Closed token choices and finite
numeric ranges allow authored hierarchy and contrast without arbitrary CSS, font URLs or paint
strings. Existing font stacks and native primitives remain the rendering ingredients.

Older scenes and documents retain their existing read and validation paths. Omitting the new
fields preserves established appearance; old records, retry identities and immutable published
snapshots must not be rewritten by this feature. Explicit use of the new styling opts into the
new scene/document versions. Compatibility, renderer agreement and export behavior require their
own implementation checks.

This record establishes the public inspection and the original design brief. It reports no
completed implementation test counts, visual acceptance or deployment result. Those results
belong in the implementation evidence after the corresponding checks finish. Human task
observations, native-language review, manual assistive-technology checks and physical-device
acceptance remain separate evidence.
